# Music I Like

This is a beginner-level HTML and CSS website about five music artists: Pink Floyd, Kanye West, MF DOOM, Radiohead, and Tyler, The Creator.

## Files
- `index.html`: Homepage and introduction.
- `artists.html`: Information about each artist.
- `albums.html`: Five album descriptions and a comparison table.
- `style.css`: Styles shared by all three pages.

## Features
- Three pages connected by navigation links.
- Semantic HTML elements including header, nav, main, section, article, and footer.
- Headings, paragraphs, links, and a table.
- Basic colors, margins, padding, borders, and typography.
- Flexbox used for the artist cards.
- A media query to make the pages easier to use on small screens.
